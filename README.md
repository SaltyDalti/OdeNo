# Ode No!

A terminal story by Dalton Stout. May 1824. Beethoven has lost the pages of the 9th symphony across Italy and has to reach Vienna with them.

## Play

```bash
python3 main.py
```

Move by compass direction. Nine manuscript pages are on the map. An old man in Perugia gives a boat pass if you can name Bari. Vienna with all nine pages wins. Vienna short of nine loses. Stepping off the map sends you back to Aosta.

One file. No dependencies.
